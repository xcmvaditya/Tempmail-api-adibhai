# 📧 Mail.tm Temp Email API

**Developed by Genius Hacker Aditya**

Serverless API on Vercel — create temp emails, read inbox, delete accounts. Powered by [mail.tm](https://mail.tm).

---

## 🚀 Deploy

### Option 1: One-click Vercel
1. Fork this repo on GitHub
2. Go to [vercel.com/new](https://vercel.com/new)
3. Import the forked repo
4. Click **Deploy**
5. Done ✅

### Option 2: CLI
```bash
npm i -g vercel
vercel --prod
